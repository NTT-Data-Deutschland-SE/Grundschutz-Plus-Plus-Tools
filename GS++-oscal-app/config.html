Prompts

Jedes Tool meldet seine Prompts beim Start hier an — samt Standardtext. Bearbeitet wird also immer der aktuelle Stand des jeweiligen Tools, ohne dass die Texte doppelt gepflegt werden müssten. Ein Tool, das noch nie geöffnet wurde, taucht erst nach dem ersten Start auf.

Quellen und Pins

Kataloge und Hilfsdateien hängen an einem festen Commit, damit dieselbe Eingabe morgen dasselbe Ergebnis liefert (Handbuch 3.13/3.14, Grundregel 8). Aktuell bleiben Sie trotzdem: „Nach Updates suchen" holt den neuesten Commit der jeweiligen Datei, zeigt ihn an und übernimmt ihn erst auf Klick.

Nur zum Auflisten von Verzeichnissen und zur Update-Prüfung — ein Token ohne Rechte („public repo, read-only") genügt. Ohne Token erlaubt GitHub 60 Anfragen pro Stunde und meldet danach 403; mit Token sind es 5000. Die Anmeldung im Browser hilft dabei nicht: api.github.com wertet keine Session-Cookies aus. Der Token bleibt im localStorage dieses Browsers.

Speicher

Artefakte liegen in der IndexedDB gpp-artefacts, Einstellungen im localStorage unter gpp:cfg:. Ohne eingerichtete Zusammenarbeit verlässt beides diesen Browser nicht; mit angemeldeter Datenbank werden Artefakte zusätzlich dorthin übertragen — API-Schlüssel, GitHub-Token und Prompts nie.
